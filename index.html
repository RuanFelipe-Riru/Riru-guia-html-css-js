As 3 camadas de uma página

Pense numa casa. O HTML é a estrutura (paredes e portas). O CSS é a pintura e a decoração. O JavaScript é a parte que se mexe, como a luz que acende quando você aperta o interruptor.

Regras de ouro

  1. 1Abriu, fecha: tags, aspas, parênteses e chaves.
  2. 2Maiúscula importa em nomes de variável, função e arquivo.
  3. 3Cada id é único na página.
  4. 4Listas começam no 0.
  5. 5Definir uma função não é chamar a função.
  6. 6Use === para comparar, = para guardar.

Erros que todo iniciante comete

  • Esquecer de fechar uma tag ou usar </p> fora de ordem.
  • Escrever color red; sem os dois pontos no CSS.
  • Procurar um id que não existe e receber null.
  • Usar = dentro do if em vez de ===.
  • Caminho errado de imagem ou arquivo, e maiúscula no nome.
  • Salvar o arquivo e esquecer de recarregar a página (Ctrl+F5).

Dicionário de códigos

É a sua tabela de consulta: HTML todas as tags, CSS todas as propriedades, JavaScript comandos e métodos essenciais, e os atalhos do VS Code. Cada linha mostra o código, um exemplo de uso e o significado, organizada por linguagem.

Lista abrangente com praticamente todas as tags HTML, propriedades CSS e comandos/métodos essenciais de JavaScript em uso hoje. Tags e propriedades totalmente obsoletas (removidas dos navegadores modernos) foram deixadas de fora.

Linhas com fundo verde são códigos importantes ou mais difíceis. Vale estudar esses com mais atenção. São os que mais aparecem na prática e os que costumam dar mais trabalho. Os exemplos são genéricos de propósito, para servirem em qualquer projeto:

  • HTML: for, rel, link preconnect, script no fim do body e os caminhos de arquivo (pasta/ e ../).
  • CSS: margin 0 auto, border-radius 50%, box-shadow com valores, inline-block, relative + absolute, @keyframes em porcentagem, transition entre estados e a seção Seletores, cores e unidades (.classe, #id, *, .a.b, .pai .filho, rgba, linear-gradient, px/%/vh/rem).
  • JavaScript: const em MAIÚSCULAS, null, definir x chamar função, função sem parênteses, return, resto (%), concatenar texto, inverter com !, lista.length e lista[i], for percorrendo lista, String(), Math.floor em divisão, id do setInterval, evento change e classe no pai.
  • VS Code e navegador: Ctrl+Z, Esc, F12, F5 / Ctrl+F5 e Win + . para emojis.
